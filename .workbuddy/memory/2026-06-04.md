- **stockApi.ts** — 将硬编码的 westock-data 绝对路径改为 `path.resolve(__dirname, 'westock-data/...')` 相对路径；因 ESM 环境无 `__dirname`，加了 `fileURLToPath(import.meta.url)` polyfill。
- **KlineChart.vue** — 新增 MA30/MA40/MA50/MA60 均线，默认隐藏（legend selected: false），点击图例可像 MA20 一样切换显示。
- **Toolbar.vue** — ① 第 1000 天时总资产可点击编辑；② 新增「清缓存」按钮（重置右侧），调用 `cacheManager.clear()` 清除 localStorage 中 `stock-cache:*` 的 K 线和行情缓存，保留自选股列表（`stock-sim-watchlist`）和数据源设置，然后 `location.reload()` 强制刷新。
- 创建 **README.md**，顶部展示 image.png UI 截图，包含项目简介和快速启动说明。
- **RealDataSource.ts** — 修复真实数据源刷新卡死/不变的 bug。根因：`simDay` 初始值 1000 固定，但 API 拉取的真实 K 线通常不足 1000 条，导致 `manualRefresh()` 的条件 `simDay < maxKlineDays()` 永远为 false，数据永远不变。修复：① `fetchDailyKline` 加载 K 线后调用 `clampSimDay()` 将 simDay clamp 到实际数据量；② `reset()` 使用 `Math.min(SIM_INITIAL_DAYS, maxKlineDays())`；③ `getKline()` 改为 `daily.slice(0, simDay)` 截取，与 MockDataSource 行为一致，实现刷新时渐进添加数据。
- **ChartPanel.vue** — ① 全屏切换按钮；② 全屏时保存当前 `simDay`，切换到 `MOCK_HISTORY_DAYS`(2000) 展示全部 K 线；退出全屏时恢复保存的天数。
- **TradePage.vue** — 新增 `isChartFullscreen` ref，provide 给子组件；全屏时面板全部隐藏。
- **TradeLayout.vue** — 注入 `isChartFullscreen`，左右底容器和分割线加 `hidden`（display:none），中间图表占满视口。
- **market.ts** — 新增 `setSimDay(day)`：直接跳转到指定天数，同步更新 dataSource 和 store。② `initQuoteSubscription` 批量拉取/占位兜底/名称补充（localStorage 缓存 + API fallback）。③ 新增 `initRealMode(codes)`。
- **TradeLogPanel 成交日期改天数** — ① `TradeRecord` 接口新增 `simDay` 字段；② `trading.ts` placeOrder 时从 `marketStore.simDay` 获取当前模拟天数写入记录；③ `TradeLogPanel.vue` 成交日期列改为 `第${r.simDay}天`，不再显示真实日期。后续改为表头「成交日（天）」+ 纯数字显示。
- **交易手续费计算修正** — 之前只算了佣金（万三最低5元），缺少印花税和过户费。修正为 A 股标准：佣金（万三，最低5元）+ 过户费（万分之一，双向）+ 印花税（万分之五，仅卖出）。
- **README.md** — 新增「模拟数据算法」章节（随机漫步模型、OHLC 生成公式、定时器驱动）和「手续费算法」章节（三方费用明细、计算公式、示例表格）。
