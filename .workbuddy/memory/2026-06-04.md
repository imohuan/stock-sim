## 2026-06-04

### CLI 修复与增强

**问题修复：**
- PID 文件路径从 `__dirname` 改为 `os.homedir()/.axtools/stock-sim/.pid`，解决 npx 临时目录导致 stop 找不到 PID 文件的问题

**行为变更：**
- `start` 命令现在会先调用 `tryStop()` 关闭旧服务，行为与 restart 一致

**新增功能：**
- 服务器新增 `/info` 端点，返回纯文本 `stock-sim`，用于进程身份识别
- CLI 新增 `kill` 命令：
  - 读取 `~/.axtools/stock-sim/.ports` 中记录的所有端口
  - 并发请求每个端口的 `/info`，确认是 stock-sim 才执行 kill
  - Windows 使用 `netstat -ano | findstr :<port>` 获取 PID，然后 `process.kill()` 终止
  - 支持跨平台（Windows/macOS/Linux）
- `start` 自动将端口追加到 `.ports` 文件

**修改文件：**
- `bin/server.mjs` — CLI 主脚本
- `server/index.ts` — 添加 `/info` 路由
